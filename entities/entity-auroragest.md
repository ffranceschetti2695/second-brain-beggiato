# AuroraGest

Piattaforma SaaS multi-tenant cloud per la gestione di patrimoni immobiliari in affitto. È il prodotto core che genera la quota maggiore dell'[[concetto-arr]] di Aurora Sistemi.

## Funzionalità principali

- Anagrafica unità, conduttori e contratti
- Incasso automatico canoni (SEPA, RID, bonifico)
- Gestione scadenze e rinnovi con alert proattivi
- Ticketing manutenzioni con assegnazione fornitori
- Reportistica fiscale (CU, registrazione contratti AdE)
- **Modulo AI previsione morosità** (lanciato gennaio 2024 — differenziatore competitivo)
- API aperte per integrazioni custom

## Tech stack

SaaS multi-tenant, AWS EU, backup giornaliero, crittografia AES-256. Integrazioni native: Immobiliare.it, Idealista, TeamSystem, Zucchetti.

## Piani

Starter €490/mese (fino a 200 unità) · Business €1.200/mese (fino a 1.000 unità) · Enterprise su preventivo.
